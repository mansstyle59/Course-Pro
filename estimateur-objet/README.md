# Estimateur d'objet — Chasseur de bonnes affaires

Application web mobile en français pour calculer une rentabilité indicative d'achat-revente.

## Fonctionnalités
- Import d'une photo depuis mobile
- Champ de lien Leboncoin, Marketplace ou autre
- Catégorie, état, détails de l'objet
- Calcul de prix de revente indicatifs, coûts, bénéfice, marge, ROI et prix d'achat maximal
- Historique local et partage du résultat

## Limites actuelles
La photo est uniquement affichée dans l'interface : elle n'est pas encore analysée par une IA. Le champ de lien ne récupère pas automatiquement le contenu des plateformes. Les fourchettes sont des scénarios de calcul et non des prix de marché vérifiés.

## Publication GitHub Pages
Pour publier ce fichier depuis ce dépôt : dans GitHub, ouvrez Settings → Pages, sélectionnez Deploy from a branch, choisissez main et le dossier / (root), puis Save. Cela publiera le site principal du dépôt, pas ce fichier dans un sous-dossier. Pour avoir un lien Pages autonome dédié à l'application, il faut déplacer/copier le contenu vers la racine d'un dépôt dédié nommé `estimateur-objet` ou configurer un workflow Pages spécifique.
